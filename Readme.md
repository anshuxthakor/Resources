# Resources

> A growing collection of personal notes, references, study material, and learning resources collected while learning software development.

The purpose of this repository is to keep useful technical knowledge in one place.

Instead of leaving concepts scattered across browser tabs, notebooks, videos, PDFs, and random files, this repository organizes them into readable notes that can be revisited whenever needed. It acts as a personal reference library for understanding technologies, reviewing important concepts, practicing code, and preparing for interviews.

The resources are written while learning. Some topics are explained from the beginning, while others go deeper into how a technology works internally. The notes focus not only on syntax, but also on the reasoning behind the syntax, how different concepts connect, where common mistakes happen, and how the technology is used in real projects.

The repository currently covers topics from several areas of software development, including:

- HTML and semantic web structure
- CSS, layout systems, animations, variables, and responsive design
- JavaScript fundamentals and advanced concepts
- DOM structure, browser rendering, and DOM events
- React.js concepts, hooks, forms, routing, state management, and application architecture
- TypeScript types, interfaces, generics, tuples, unions, and React integration
- Redux Toolkit and global state management
- Backend fundamentals and Node.js
- Git and GitHub workflows
- Interview questions and preparation material

The repository includes both Markdown notes and PDF resources. Markdown is used for detailed explanations, code examples, topic breakdowns, and practical learning modules. PDFs are included as additional reference material for revision and deeper study.

The notes are not intended to be a formal textbook or an official replacement for documentation. They are personal learning resources written in a way that makes concepts easier to understand and remember. Official documentation should still be consulted for the most accurate and up-to-date information, especially when working with tools, frameworks, APIs, and production systems.

A typical learning note may include:

- A simple explanation of the concept
- Real-world analogies
- Important terminology
- Code examples
- Step-by-step breakdowns
- Comparisons between similar ideas
- Common beginner mistakes
- Practical use cases
- Quick revision notes
- Practice questions or activities

The goal is to move from memorizing a definition to building a useful mental model.

For example, learning React is not only about memorizing hooks. It is also about understanding rendering, state updates, component relationships, effects, references, and data flow. Learning Git is not only about remembering commands. It is about understanding project history, commits, branches, collaboration, recovery, and the reason teams use version control.

This repository is continuously growing. New resources are added as new technologies are learned, existing topics become clearer, and older notes are improved through practice.

The learning process behind this repository is:

```text
Learn a concept
      ↓
Practice with examples
      ↓
Find mistakes and edge cases
      ↓
Understand how it works
      ↓
Explain it clearly
      ↓
Save it as a reusable resource
```

Writing the notes is part of the learning process itself. If a concept cannot be explained clearly, it usually means there is still something left to understand.

This repository is useful for:

- Revising previously learned topics
- Reviewing concepts before starting a project
- Understanding the foundation behind frontend and backend technologies
- Preparing for technical interviews
- Keeping personal notes organized
- Comparing related concepts
- Finding examples while building applications
- Tracking progress while learning software development

The resources are organized around continuous learning rather than a fixed course structure. Topics can be read in order, studied independently, or used as references when a particular concept is needed.

The most important idea behind this repository is simple:

> Learning is stronger when knowledge is understood, practiced, explained, and revisited.

This collection will continue to grow one concept, one explanation, and one page at a time.
